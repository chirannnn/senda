# Public demo script (for a reviewed local demo)

This script describes a short local demonstration. Use only a permitted local
simulator fixture and non-sensitive test data. Do not present it as a customer
deployment.

1. Show the runtime's service-readiness check and the local PostgreSQL
connection boundary.
2. Show an event chunk being validated and committed with its checkpoint.
3. Show the derived fact fields and separate pickup/engagement formulas.
4. Walk through an evidence-gated prompt candidate and its simulator
   validation result.
5. Show the approval state and exact configuration version required before
   apply.
6. Show how an ambiguous operation is reconciled or held for manual review.
7. Close by showing the audit record and the limits: no hosted UI, no
   production auth/tenant isolation, and no full optimized-workload result.

Do not use hidden scenario state, private run files, real customer records, or
unverified performance claims in a public demo.

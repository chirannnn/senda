# Senda positioning

## Position

Senda is an intelligent outbound operations platform direction for teams that
need to improve engagement workflows using observed outcomes, controlled
evaluation, and governed changes.

## The problem it addresses

Outbound teams often configure a workflow, inspect fragmented reports, and
make changes based on limited or difficult-to-reproduce evidence. A single
aggregate rate can hide where outcomes change; a promising variant can harm a
separate guardrail; and an untracked configuration edit can make later
analysis unreliable.

## How the approach differs

Senda's approach treats operational records and decisions as one traceable
system: preserve source events, derive explicit measures, compare relevant
populations, require approval for sensitive changes, and observe the result.
The current repository demonstrates parts of this approach in a controller
prototype. It does not establish market differentiation, customer outcomes,
or a complete commercial product.

## Audience

The initial audience hypothesis is operations leaders and platform teams that
own outbound voice programs and need measurable, reviewable workflow changes.
This is a product hypothesis, not a validated customer segment. More detail is
in [target market](../business/TARGET_MARKET.md).

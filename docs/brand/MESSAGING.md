# Senda messaging

## One-line description

Senda helps outbound operations teams measure workflow outcomes and improve
them through evidence-led, governed decisions.

## Short description

Senda is an intelligent operations platform direction for understanding
outbound engagement, comparing changes with observed evidence, and keeping
sensitive workflow updates reviewable and controlled.

## Message pillars

### Understand operations

Preserve event provenance, data quality, configuration versions, and
population context so operators can ask what changed and when.

### Measure meaningful outcomes

Keep pickup and engagement distinct, and make the denominator visible.

### Improve with evidence and control

Use deterministic comparisons and human approval for sensitive changes;
reconcile uncertain outcomes rather than treating a timeout as success.

## Claim discipline

Use “prototype” for the current repository. Avoid “production-ready,”
“autonomous,” “customer-proven,” “faster,” or capacity claims without
corresponding evidence. Do not imply the product is currently available to
customers.
